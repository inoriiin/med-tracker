📖 BACKEND & HOSTING INSTRUCTIONS

1. Live Web Hosting (GitHub Pages - Free)

  1. Create a GitHub account and start a new public repository named med-tracker.
  2. Upload this exact file as index.html.
  3. Go to Settings -> Pages, set Source to Deploy from a branch (main / root) and save.
  4. Your app will be live at https://yourusername.github.io/med-tracker/!

2. Simple Shared Backend (JSONBin.io)

  1. Go to JSONBin.io and register a free account.
  2. Click your profile top-right -> API Keys -> copy your Master Key.
  3. Open ⚡ SYNC CONFIG in this app, select JSONBin.io, paste the Master Key, and click Auto-Create New Shared Bin.
  4. Copy the generated Bin ID and send both the Master Key and Bin ID to your SO. Once entered on her end, both devices share identical updates instantly!
